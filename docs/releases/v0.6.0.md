**OpenASCII now speaks English.** On first launch it asks for your language (English or Portuguese), and you can change it any time in Settings. This release also brings a different wallpaper on each monitor, deleting your own wallpapers from the launcher and a truly blank template.

*O OpenASCII passa a falar inglês e português: na primeira vez pergunta o idioma, que se muda nas Definições. Também traz um wallpaper diferente em cada monitor, apagar os teus wallpapers com o botão direito e um modelo "em branco" a sério.*

## Which file to download

| File | For |
|---|---|
| **`OpenASCII-0.6.0-setup.exe`** | Most people. Installs just for your user, no admin rights. Asks whether you want the 28 built-in wallpapers and whether the app should start with Windows. |
| `OpenASCII-0.6.0-win64.zip` | Portable: extract and run `openascii.exe`. Turn on starting with Windows in Settings. |
| `SHA256SUMS.txt` | To check the files: `Get-FileHash <file>`. |

The executable isn't signed yet, so SmartScreen may show "Windows protected your PC". Click **More info › Run anyway**.

## What's new

- **Languages**: English and Portuguese across the whole interface (launcher, tray menu, first steps, dialogs, wallpaper descriptions). Built to grow: each language is one translation table.
- **A different wallpaper on each monitor**: on a wallpaper's page, under "monitors", pick the screens that get it just for them. Settings shows what each monitor has. Monitors are recognized by the device, so the choice survives Windows renumbering them.
- **Delete your wallpapers**: right-click a wallpaper in the launcher's list for apply, edit code, open folder and delete. Deleting only works on wallpapers you created and always asks first, warning that it can't be undone.
- **A truly blank template**: "New wallpaper › blank" now shows just a simple text you change in `wallpaper.toml`, plus five effects in comments (mouse ripples, rain, stars, clouds, colors) that you turn on by deleting the `//`. They stack, so you can turn them all on at once.
- **A short tray menu**: left-click the tray icon for Open OpenASCII, Pause and Quit. Right-click opens the full menu with wallpapers, variants and quick adjustments.

Full list in the [CHANGELOG](../../blob/v0.6.0/CHANGELOG.md) (in Portuguese).

## Upgrading from 0.5.0

Run the new installer over the old one: your settings, tweaks and wallpapers stay. The app asks for the language once.

## Known limitations

- Wallpapers on their own monitor don't update live yet when you tweak them or edit their code; changes show when they reload.
- The wallpaper creation guide and the technical docs are still in Portuguese.
